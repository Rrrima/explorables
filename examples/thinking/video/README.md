# Thinking Inside the Box · the explainer

An 86-second TED-Ed style explainer drawn live on canvas in the essay's hand (a thin grey pen, one blue watercolour, small figures and translucent cubes), with voice, music and effects. Viewers can pause anywhere and ask a question; the kit's agent researches an answer and makes a short clip.

- `segments.json`, `SCRIPT.md` — the narration (ten scenes, 223 words) and the two-column script.
- `explainer.json` — the agent's context, the props the style can draw, voice pacing, music, effects and cues.
- `lib/` — the essay's engine (`paper.js`, `pen.js`, `wash.js`); `style.js` implements the kit's style contract with it; `scenes.js` draws one scene per segment and the end card.
- `schedule.json`, `captions.srt`, `audio/` — generated by the kit's pipeline.

Run it with the explorable skill's kit:

```
node kit/server/server.mjs ./llm-thinking-explainer --port 8921     # http://localhost:8908/  (ANTHROPIC_API_KEY for asking)
node kit/pipeline/build.mjs ./llm-thinking-explainer mix            # re-mix after changing cues
```

The header links back to the essay at `http://localhost:8907/`.
