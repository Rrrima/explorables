# The Half Shell · the explainer

A 93-second explainer for the essay *The Half Shell* (http://localhost:8905/), on the explainer kit (`~/project/explainer-kit`): pause it, hover the drawings and ask questions.

- `SCRIPT.md`: talking points and the two-column script (10 scenes, 215 words, about 2.5 words a second)
- `segments.json`, `explainer.json`: narration, the ask agent's context, props, voice (speed 0.92, pauses), music, sound effects and cues
- `lib/`: the essay's own engine, copied: `wc.js` (watercolour washes, gloss, light), `things.js` (oysters, ice, platter, glasses…), `geo.js`, `data.js`
- `style.js`: the kit's style contract built on that engine (cached lit sprites over the essay's baked wood table)
- `scenes.js`: ten scenes, each tied to spoken words; reuses the essay's vignettes (porter, oyster cellar, condemned bed, nickels, magnifier, real-coastline map, year wheel, true-scale lineup, tap-test tray)
- `schedule.json`, `captions.srt`, `audio/`: generated by `node ~/project/explainer-kit/pipeline/build.mjs .`

Run: `node ~/project/explainer-kit/server/server.mjs ~/project/oysters-v2-explainer --port 8803`.

Notes: the build needs `NODE_USE_ENV_PROXY=1` inside a proxied sandbox so Node's fetch reaches ElevenLabs and Stability. Every number comes from the essay's `data.js` and research report.

Version control: `git init` was blocked by the build sandbox (it cannot write `.git/`), so this folder is not yet a repository. Run `git init && git add -A && git commit -m "initial"` here to version it.
